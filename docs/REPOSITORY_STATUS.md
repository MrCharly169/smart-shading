# Repository status

This repository contains the complete Smart Shading 4.6.0-beta.1 source tree.

Included:

- Home Assistant custom integration under `custom_components/smart_shading`
- Lovelace card JavaScript
- German and English translations
- brand assets
- unit and runtime regression tests
- release builder
- GitHub Actions validation
- installation and architecture documentation

The former archive bootstrap directories are not part of the finished repository and must not be restored.
