# Repository status

This repository contains the complete Smart Shading source tree.

Included:

- Home Assistant custom integration under `custom_components/smart_shading`
- canonical Lovelace card resource at `/smart_shading/shading.js`
- backward-compatible loader for the former card URL
- English repository documentation and bilingual English/German Home Assistant UI
- brand assets
- unit and runtime regression tests
- package and metadata validation
- pull request changelog policy
- automated tagged GitHub releases

The active version is defined only in `custom_components/smart_shading/manifest.json`. Work that has not been released yet is documented under `CHANGELOG.md → Unreleased`.

The former archive bootstrap directories are not part of the finished repository and must not be restored.
