# Baseline

## Version

`4.6.0-beta.1`

## Why this baseline

This version is the last package preserved as an installable, testable Home Assistant integration before further UI restructuring. Future changes should be made incrementally so regressions can be attributed to a specific pull request.

## Compatibility target

- Home Assistant 2026.6+
- Config entry schema version 9
- Integration domain `smart_shading`
- Card resource `/smart_shading/smart-shading-card.js?v=4.6.0-beta.1`
