# Smart Shading support

## Start here

1. Read the [Quick Start](README.md#quick-start) and [FAQ](docs/FAQ.md).
2. Confirm the installed Smart Shading version, Home Assistant version, `sun.sun` availability, dashboard resource URL, selected sector source, and current Card reason.
3. Check the [changelog](CHANGELOG.md) for a related fix or migration note.

## Setup and usage help

Use the README and FAQ for installation, Easy/Advanced selection, dashboard setup, waiting inputs, and KNX false-movement diagnosis. The [Advanced behavior guide](docs/ADVANCED_MODE.md) documents schedules, holds, glare protection, maximum opening, and command execution.

## Reproducible defects

Search [existing issues](https://github.com/MrCharly169/smart-shading/issues) first. If the problem is new, use the Bug Report template and include:

- Smart Shading and Home Assistant versions;
- Easy or Advanced Mode and the affected cover profile;
- expected and observed behavior;
- exact reproduction steps;
- the Card's displayed reason and relevant sanitized diagnostics/logs;
- whether the problem also occurs with the latest applicable release.

Remove personal names, entity IDs, addresses, URLs, tokens, and installation-specific data before posting. Do not post security vulnerabilities publicly; follow [SECURITY.md](SECURITY.md).

Feature ideas belong in the Feature Request template. Development and pull-request guidance is in [CONTRIBUTING.md](CONTRIBUTING.md).
